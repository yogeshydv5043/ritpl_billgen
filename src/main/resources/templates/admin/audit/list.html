SEPARATION OF CONCERNS

Definition, quota and history

These three things are deliberately independent — editing one never rewrites another:

  • Audit event definitionThis registry: what counts as an event and which plans may produce it.
  • Usage quotaPer-account event ceiling inside one window — the plan caps plus this type's own limit, whichever is stricter.
  • Audit historyImmutable rows in audit_records, protected by an append-only trigger; the retention purge is the only DELETE permitted and only in a session that declares its cutoff.
