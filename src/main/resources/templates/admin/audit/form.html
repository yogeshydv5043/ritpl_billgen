Limit period & quota

One period is used at a time, exactly as the administrator picks it.
Choose NONE for unlimited recording, CUSTOM to define your own window length.
Counted per account, in addition to the plan's own audit caps.
Only read when the limit period is CUSTOM.
A notification rule or job can target this threshold; it never blocks recording by itself.

! A quota is reported and alerted, never used to silently drop an event. If the limit is reached the event is still written and the excess is visible in usage — losing evidence is worse than exceeding a cap.
